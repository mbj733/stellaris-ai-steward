# data/ · 可选增强数据

本目录默认为空。**仓库按版权考虑不携带任何游戏数据**；以下文件均为可选，
由你自己从**本机游戏安装**生成，用于提升决策质量：

| 文件 | 生成脚本 | 说明 |
|---|---|---|
| `event_index.json` | `tools/build_event_index.py` | 事件结构索引（触发器/效果/权重） |
| `loc.json` | 同上（依赖你自备的本地化缓存） | 选项名字等（仅供本机使用，请勿再分发） |
| `modifier_index.json` | `tools/mod_index_build.py`（若附带） | 修正符参数索引 |

用法：打开脚本，把顶部标有**占位符**的路径（游戏安装目录等）改成你自己的路径，然后运行。
没有这些数据工具也能正常工作（决策质量略降，多选项改为"盲探合法解"）。
