Stellaris AI Steward
群星 AI 托管

单机《群星》辅助值守工具——事件自动按「合法最优解」处理、一键托管、游戏内悬浮面板、全程审计。

A single-player Stellaris stewardship tool — auto-resolve events with a best-legal-choice engine, one-tap AI autopilot, a floating in-game panel, and a full audit trail.

所有操作均为对运行中游戏进程的临时内存读写，不修改任何游戏文件，游戏退出即全部还原。

All operations are runtime memory reads/writes on the running game process only — no game file is ever modified, and everything reverts when the game exits.

功能一览Feature highlights

从事件应答到面板值守，一切围绕着「像你在玩，但从不失误」。

From event resolution to idle stewardship — it plays like you would, but with a rulebook.

⚡

事件全自动Automatic event resolution

单选项直接处理；多选项按「参谋偏好」逐个探测，取游戏接受的第一个（= 合法且最优）。

Single-option events handled instantly; multi-option events are probed in preference order and the first choice accepted by the game is taken — the best legal choice.

🎛

一键托管One-tap autopilot

面板按钮 / F8 全局热键，切换游戏自带的 human_ai 托管——帝国由游戏 AI 自动发展，决策受本工具把关。

Panel button / F8 global hotkey toggles the game's built-in human_ai autopilot — your empire develops automatically, with every decision policed by this tool.

🧠

决策改写Decision rewriting

已学习的多选项事件家族自动「武装」——无论选择来自 AI 托管还是游戏自发结算，都会被替换为参谋决策；归属校验保证绝不触碰其他帝国。

Learned multi-option event families are armed — any selection, from any source, is replaced with the steward's choice at execution time. An ownership guard ensures other empires are never touched.

📌

悬浮面板Floating panel

随游戏自动出现，实时显示 武装 / 改写 / 归属拦截 / 待决；可拖动、可关闭、中 / EN 一键切换。

Appears automatically with the game; live armed / rewrites / blocked / pending counters; draggable, closable, with a 中/EN toggle.

🛡

审计与自愈Audit & self-healing

每 10 分钟健康心跳；钩子 / 面板 / 进程全部自动恢复；一切决策双侧留痕。

10-minute health heartbeats; hooks, panel and processes all recover automatically; every decision is logged on both the game side and the tool side.

⚔

战争组件（可选）War component (optional)

战时自动接敌、同星系追击、空闲舰队增援最近受威胁星系；F9 可切到进攻模式（推进最近敌国）。需安装本地 mod 并重启游戏一次。

Wartime auto-engage, in-system pursuit, and idle-fleet reinforcement of the nearest threatened system; F9 switches to attack mode (push to the nearest enemy system). Requires a local mod and one game restart.

三步安装Install in three steps

要求：Windows + Python 3.10+ + Stellaris 4.5.2

Requirements: Windows + Python 3.10+ + Stellaris 4.5.2

1

安装 PythonInstall Python

从 python.org 下载安装（务必勾选 Add Python to PATH）。

Download from python.org (make sure to check Add Python to PATH).

2

双击安装脚本Double-click the installer

双击 install.bat：自动创建虚拟环境、安装依赖、可选开机自启、冒烟自检。

Run install.bat: it creates a venv, installs dependencies, offers a startup entry and runs a smoke self-test.

3

启动游戏Launch the game

面板自动出现，值守开始。不需要把任何文件放进游戏目录。

The panel appears by itself. Nothing needs to be copied into the game folder.

版本说明：本工具针对 Stellaris 4.5.2 (Cygnus) 的内存布局制作，内置版本指纹校验——游戏版本不符时会拒绝运行（防止改错地址导致游戏崩溃）。
Version note: built against Stellaris 4.5.2 (Cygnus) with a version fingerprint guard — the tool refuses to run on a different game build (to avoid corrupting memory).

面板速查Panel cheat sheet

上班挂机 = 两个开关都开；回来自己玩 = 两个都关。

Idling at work = both switches ON; playing yourself = both OFF.

控件 作用
「切换 开/关」/ F8 托管：开 = 游戏 AI 替你发展帝国（决策受本工具把关）；关 = 帝国操作留给你
「离开模式」 人不在时打开：事件全自动应答 + 时间防冻结
「战争模式」/ F9 默认防御（自动接敌 + 增援受威胁星系）；F9 切进攻（空闲舰队推进最近敌国）。需先安装战争组件并重启游戏
引擎状态行 实时读数：武装 N 条 · 改写 M 次 · 归属拦截 B · 待决 K
中 / EN 面板语言切换（记忆上次选择）
