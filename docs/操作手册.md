# AI 托管 · 操作手册（2026-10-16）

一群常驻小程序 + 内存级钩子，让《群星》在你离开时依然：时间持续流动、事件全自动按最优解处理、一切决策可审计、故障全自动恢复。

## 三个开关（面板：游戏启动后自动出现的小窗）

| 控件 | 作用 |
|---|---|
| 「切换 开 / 关」按钮（或 F8） | **托管**开关：开 = 游戏 AI 替你玩（发展自动推进），关键选择会被参谋引擎替换；关 = 只照顾事件与时间流动，帝国操作留给你 |
| 「离开模式」按钮 | **离开模式**：事件全自动应答 + 防冻结。你人不在时打开 |
| 引擎行（小字） | 实时状态：`武装 N 条 · 改写 M 次 · 拦截 B · 待决 K` |

窗口行为：随游戏启动自动出现；你点 ✕ 关闭 → 本局不再弹；它自己崩了 → 12 秒内自动回来。

## 常见问题

- **想全自动发展**：把「托管」和「离开模式」都打开。只开离开模式 = 事件自动 + 时间流动，但帝国不主动发展（系统会在 R5 与摘要里提醒"科研疑似停滞"）。
- **怕 AI 乱决策**：多选项事件的决策由参谋引擎打分选择，并有内存级改写把游戏 AI 的选择替换为参谋优选；归属校验保证**绝不误伤其他帝国**。
- **游戏重启后要做什么**：什么都不用做。钩子/武装/组件会在 1 分钟内自动就位。

## 命令速查（在 `.` 下运行）

| 命令 | 用途 |
|---|---|
| `python tools\digest.py [--hours 8]` | 回归摘要（一页看完这段时间发生了什么） |
| `python tools\soak_report.py --since "2026-10-16 22:53"` | 时段质量报告（处理数/失败/改写/异常） |
| `python tools\selftest_all.py` | 16 项全量自检 |
| `python tools\hook_rw88.py read` | 内存钩子状态（武装表/改写数/归属拦截数） |
| 日志 | `logs\decisions.log`：[R1] 事件处理 · [R6] 健康心跳 · [审计] 决策流水 · [R2]/[R5] 资源/任务 |

## 无人值守时的自动化行为

1. **事件应答**：单选项直接处理；多选项按参谋偏好顺序逐个探测，取第一个被游戏接受的（= 合法且最优）；
2. **决策改写**：对已学事件家族预置"按名武装"——游戏任何来源的选择（AI 托管、游戏自发结算）都会被替换为参谋决策；
3. **防冻结**：空闲暂停 6 秒内自动续跑；每次事件处理完自动恢复运行；
4. **自愈**：钩子被清 / 状态文件丢失 / 面板崩溃 / 进程死亡 —— 全部自动恢复，无需人工；
5. **心跳**：每 10 分钟一行健康记录（钩子在线性/武装数/改写数/拦截数/待决数/处理统计）。
6. **窗口清理**：离开模式下，外交收件类窗口（如「被宣战」通知）滞留 ≤45 秒即自动关闭，挂机回来不再有无人确认的弹窗。

## 安全边界

- 所有内存操作只动本局进程，游戏重启即完全消失（需要时会自动重装）；
- 回滚：`python tools\hook_rw88.py revert` 一键还原钩子（恢复游戏原始字节）；
- 面板开关都关着时，系统在你手动游玩时**绝不动作**（只旁观）；
- 彻底停用：结束 watchdog/brain/panel 进程并删除其开机启动项（或告诉我来做）。
