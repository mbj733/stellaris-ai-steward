# Stellaris 托管决策策略库（v1）

> 用途：AI 决策托管（brain.py / 未来决策引擎）的推理底座。
> 原则：**凡有确定性数据者以数据为准**（游戏本体 events/*.txt 的选项效果、存档数值、机制常量），
> 数据缺失处才用攻略共识/经验规则；所有规则可审计（决策日志逐条记录依据）。

## A. 事件与任务（当前监控面：R5/R8 + 建议栏）
1. **事件选项评分法**（一期目标）：
   - 从 `events/*.txt` 读选项效果，按四轴打分：
     ①经济（立刻可量化的资源/产出变化）②科研（研究点/科技/项目进度）
     ③扩张（殖民/星基/领土）④风险（外交惩罚、战争、人口损失、永久标记）。
   - 冲突裁决：风险轴为一票否决（负分且不可逆 → 除非收益 ≥2 倍优势）。
   - 无副作用/纯风味事件 → 任选（默认选项 1，减少状态扰动）。
2. **特殊项目**：新出现 → 优先研究（多数有连锁奖励）；同一项目重复出现 → 检查是否卡进度。
3. **特殊情况**：出现即入日志；进度停滞（两轮心跳无变化）→ 建议检查方针（approach）。
4. **兴趣点（POI）**：数量不降 = 有未跟进的链条 → 建议打开情况日志核对。

## B. 经济与资源（当前监控面：R2 + 建议栏）
1. 任意资源 ≥ 上限 -1 → "溢出浪费"告警（已实现：能量/矿物/食物/影响力）。
2. 能量 < 5000 或矿物 < 1500 → "储备偏低"告警（已实现；战时阈值敏感度翻倍为宜）。
3. 影响力顶上限（1000）是**纯浪费** → 最高优先级花销方向：星系宣言/星基模块/外交条约。
4. 食物长期负增长 → 注意人口饥饿事件链（数据面先记录，暂不行动）。

## C. 军事与战争（当前监控面：R6 + 摘要）
1. 军力单轮跌 >20% → 战损告警（已实现）。
2. 银河战争数变化 → 记录并提示外交核查（已实现）。
3. 战时能量消耗快（实测：1 分钟 -12K 见日志）→ 战时把能量储备阈值提升到 8000。
4. 舰队数（fleet_size）连续两轮下降（游戏未暂停）→ "持续减员"告警（**已实现：R9**，2026-10-17）。

## D. 扩张与科研（当前监控面：摘要 星基/舰队/星球/科技）
1. 星基满容量（used==cap）→ "扩张受限"告警（已实现；实例：5/5 时 AI 自行扩容到 5/6）。
2. 科技数（96 项基准）两轮心跳零增长（游戏未暂停）→ 科研停滞告警（R8 已实现）。
3. 帝国规模 vs 科技/经济增速：规模涨但军力/科技不涨 → 提示"贪多嚼不烂"（待实现，需多轮基线）。

## E. 与游戏内 AI（human_ai 托管）的分工
- 现状：托管开启时游戏 AI 全权运营，事件静默处理；本大脑负责"监督+告警+自愈+审计"。
- 未来（决策引擎 v2）：事件选项由本系统按 A1 打分后**直接执行**（执行通道攻坚中，
  链接见 kernel_findings.md「事件选项点击链」）；高风险决策（宣战/重大外交）永久保留人工确认。
